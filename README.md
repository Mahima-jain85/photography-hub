# Photography Hub

A photography-themed website with a responsive sidebar navigation menu built using HTML and CSS.

## Features

- Sidebar navigation menu
- Gallery, Exhibits, Events, Store, Contact and Feedback sections
- Interactive menu open/close functionality
- Social media icons
- Google Fonts and Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
